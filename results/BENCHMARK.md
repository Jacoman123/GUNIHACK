# Vanta benchmark

7 scenarios x 3 strategies x 10 seeds (10 drones, 1.28 x 0.96 km area, 3072 cells, 8 survivors). Generated by `python -m vanta bench --seeds 10` in 41 s.

* **Searched**: median time until every cell has been searched by some drone.
* **Mission complete**: median time until the base station knows every cell is searched and where every survivor is. A dash means some seeds never got there in 40 minutes.
* **Wasted**: cells searched again only because the drone didn't know someone had already done them, as % of the area.
* **Idle**: drone-minutes spent alive but not searching while work remained.
